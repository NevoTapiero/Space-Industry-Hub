# Space Industry Hub

פלטפורמת אדמין אישית לתעשיית החלל: מרכז בקרה כהה בהשראת SpaceX עם נתוני שיגורים חיים, מנוע ידע, ומודלים תלת ממדיים אינטראקטיביים.

## הרצה

```bash
npm install
npm run dev
```

האתר עולה על http://localhost:5199

## ארכיטקטורה (שלב 1)

- **פרונטאנד:** React 18 + Vite. עמוד יחיד עם ניווט פנימי (מרכז בקרה, לוח שיגורים, האנגר תלת ממד, מנוע ידע).
- **תלת ממד:** Three.js דרך React Three Fiber + drei. כרגע מודל פרוצדורלי בפרופורציות Falcon 9 עם הפרדת שלבים מונפשת; מוכן להחלפה במודלי glTF.
- **נתונים חיים:** אין בקאנד. הדפדפן פונה ישירות ל:
  - [Launch Library 2](https://ll.thespacedevs.com/) (The Space Devs): לוח שיגורים עולמי. חינמי, ללא מפתח, מוגבל ל~15 בקשות לשעה, לכן יש מטמון localStorage של 30 דקות.
  - [Spaceflight News API](https://api.spaceflightnewsapi.net/): חדשות תעשייה. חינמי, ללא מפתח.
- **מנוע ידע:** כרגע מאמרי יסוד ב-`src/knowledge.js` עם חיפוש טקסט בצד הלקוח.

## שלבים הבאים (Roadmap)

1. **מנוע ידע אמיתי:** להוריד תמלילי Everyday Astronaut (yt-dlp מוריד כתוביות), לפצל לקטעים, לבנות אינדקס חיפוש (בשלב ראשון lunr/minisearch בצד לקוח; בהמשך embeddings + חיפוש סמנטי).
2. **מודלי glTF אמיתיים:** Starship, New Glenn, Falcon Heavy, SLS. השוואת גדלים זה לצד זה.
3. **שידורים חיים:** ה-API כבר מחזיר קישורי webcast לכל שיגור; להטמיע נגן YouTube.
4. **בקאנד קל (אופציונלי):** פונקציית edge שמושכת את הנתונים פעם ב-10 דקות ומגישה לכולם, כדי לעקוף את מגבלת הבקשות.
